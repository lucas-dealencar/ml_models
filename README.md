# 🧠 Machine Learning Models Repository

Este repositório contém uma coleção de projetos de **Machine Learning** desenvolvidos com o objetivo de praticar e demonstrar habilidades em análise de dados, modelagem preditiva e avaliação de desempenho de modelos.

Cada pasta representa um projeto independente, baseado em datasets públicos amplamente utilizados para estudos e competições.

---

## 📁 Estrutura do Repositório

- `House Prices/`: Predição de preços de imóveis com base em características como tamanho, localização, número de cômodos, etc.
- `Titanic/`: Classificação de sobreviventes do naufrágio do Titanic com base em dados demográficos e de embarque.
- `Wine Quality/`: Previisão da qualidade de vinhos com base em características físico-químicas.

Cada pasta contém:
- Dados (ou link para download)
- Código-fonte em Jupyter Notebooks (`.ipynb`)
- Um `README.md` com a descrição específica do projeto

---

## 🚀 Tecnologias Utilizadas

- Python
- Jupyter Notebook
- Google Colab
- Pandas, NumPy
- Scikit-Learn
- Matplotlib, Seaborn

---

## 🎯 Objetivo

O objetivo principal é aplicar os conhecimentos adquiridos em Ciência de Dados e Machine Learning para resolver problemas reais e construir um portfólio técnico que demonstre:

- Pré-processamento e exploração de dados
- Seleção e treinamento de modelos
- Avaliação de desempenho
- Visualização e comunicação de resultados
